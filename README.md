# নামাজের সময় (Namaz App)

একটি সম্পূর্ণ নামাজ অ্যাপ্লিকেশন Advanced Material Design 3 UI/UX সহ।

## ফিচার:
- ✅ **নামাজের সময়** - Location-based prayer times
- ✅ **অ্যালার্ম এবং নোটিফিকেশন** - প্রতিটি নামাজের আগে
- ✅ **নামাজ ট্র্যাকিং** - ক্যালেন্ডার ভিউতে
- ✅ **স্ট্যাটিস্টিক্স** - সাপ্তাহিক/মাসিক চার্ট
- ✅ **Admin Dashboard** - সম্পূর্ণ নিয়ন্ত্রণ

## নেভিগেশন:
- 🏠 হোম (Prayer Times)
- 📊 ট্র্যাকিং (Calendar)
- 📈 স্ট্যাটিস্টিক্স
- ⚙️ সেটিংস
- 👨‍💼 Admin Dashboard

## গিটহাব-এ সেটআপ:

1. GitHub-এ নতুন Repository বানান (QuestionAnalysis)
2. github.dev দিয়ে এই প্রজেক্টের সব ফাইল আপলোড করুন
3. `.github/workflows/build-apk.yml` ফাইলটি সঠিক জায়গায় রাখুন
4. Push করুন, GitHub Actions স্বয়ংক্রিয়ভাবে APK বানাবে

## সিস্টেম প্রয়োজনীয়তা:
- **Min SDK**: 24
- **Target SDK**: 34
- **Gradle**: 8.7
- **Java**: 17+

## ডাটাবেস:
- Room SQLite Database
- 3 Tables: PrayerTime, PrayerTracking, UserSettings
